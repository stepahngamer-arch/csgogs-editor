# CS:GO GC Inventory Editor

Веб-редактор инвентаря для мода **csgo_gc** (CS:GO IS). Позволяет легко и быстро создавать файлы `inventory.txt` без необходимости вручную писать код KeyValues.

## 🚀 Возможности
* Поддержка всех скинов, ножей, перчаток, агентов и кейсов.
* Выбор износа (Wear) и качества (StatTrak™).
* Возможность задать кастомное имя (Name Tag).
* Автоматическое определение слотов и экипировка на стороны CT / T.
* **Защита от вылетов игры:** встроенная валидация `def_index` и безопасная генерация блока `default_equips`. Битые предметы (без ID) автоматически пропускаются.
* **Исправлена поддержка перчаток:** теперь им присваивается правильный `def_index` (включая Broken Fang Gloves).
* Удобный интерфейс с анимацией загрузки и адаптацией под мобильные устройства.

## 🛠 Как использовать
1. Откройте сайт: [https://stepahngamer-arch.github.io/csgogs-editor/](https://stepahngamer-arch.github.io/csgogs-editor/)
2. Выберите нужные предметы из каталога.
3. Настройте параметры (степень износа, StatTrak, имя) и нажмите «Добавить».
4. Нажмите «Скачать inventory.txt».
5. Поместите файл в папку `csgo_gc` рядом с игрой.
6. Запустите `csgo.exe` и наслаждайтесь скинами!

## ⚙️ Технические детали
* Работает полностью в браузере (без бэкенда).
* Данные предметов подгружаются с официального CSGO-API (ByMykel).
* Безопасная генерация KeyValues защищает игру от крашей при чтении конфига.
