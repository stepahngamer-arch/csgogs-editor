# CS:GO GC Inventory Editor (`csgogs-editor`)

**csgogs-editor** — это бесплатный онлайн-редактор инвентаря для мода **csgo_gc** (CS:GO IS). 
Инструмент позволяет легко и быстро создавать файлы `inventory.txt` без необходимости вручную писать код KeyValues. 

Проект создан как альтернатива ручному редактированию конфигов в блокноте и помогает избежать ошибок, которые приводят к вылетам игры.

🌐 **Ссылка на онлайн-редактор:** [https://stepahngamer-arch.github.io/csgogs-editor/](https://stepahngamer-arch.github.io/csgogs-editor/)

## 🚀 Основные возможности
* **Полная база предметов:** Поддержка всех скинов, ножей, перчаток, агентов и кейсов.
* **Гибкая настройка:** Выбор износа (Wear), качества (StatTrak™), а также возможность задать кастомное имя (Name Tag).
* **Автоматическая экипировка:** Определение слотов и распределение предметов на стороны CT / T.
* **Защита от вылетов игры:** Встроенная валидация `def_index` и безопасная генерация блока `default_equips`. Битые предметы (без ID) автоматически пропускаются.
* **Исправленная поддержка перчаток:** Корректное присвоение `def_index` для всех перчаток (включая Broken Fang Gloves).
* **Удобный интерфейс:** Анимация загрузки и адаптация под мобильные устройства.

## 🛠 Как использовать
1. Откройте сайт: [https://stepahngamer-arch.github.io/csgogs-editor/](https://stepahngamer-arch.github.io/csgogs-editor/)
2. Выберите нужные предметы из каталога.
3. Настройте параметры (степень износа, StatTrak, имя) и нажмите «Добавить».
4. Нажмите «Скачать inventory.txt».
5. Поместите файл в папку `csgo_gc` рядом с игрой.
6. Запустите `csgo.exe` и наслаждайтесь скинами!

## ⚙️ Технические детали
* Работает полностью в браузере (без бэкенда, на чистом JavaScript).
* Данные предметов подгружаются с официального CSGO-API (ByMykel).
* Безопасная генерация KeyValues защищает игру от крашей при чтении конфига.

## ❓ Часто задаваемые вопросы (FAQ)
**В: Чем этот редактор лучше ручного редактирования inventory.txt?**
**О:** Ручное редактирование в блокноте часто приводит к синтаксическим ошибкам, из-за которых игра вылетает. `csgogs-editor` автоматически валидирует `def_index` и генерирует безопасный блок `default_equips`, исключая человеческий фактор.

**В: Нужно ли что-то устанавливать?**
**О:** Нет. `csgogs-editor` работает полностью в браузере. Вам не нужно скачивать сторонние программы или библиотеки.

**В: Какие редакторы инвентаря для csgo_gc существуют?**
**О:** На данный момент большинство игроков либо редактируют `inventory.txt` вручную, либо используют устаревшие скрипты. `csgogs-editor` — это современный веб-инструмент с визуальным интерфейсом, который автоматически подгружает актуальную базу предметов из CSGO-API.
