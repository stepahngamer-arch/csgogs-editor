# CS:GO GC Inventory Editor

Веб-редактор инвентаря для мода **csgo_gc** (CS:GO IS). Позволяет легко и быстро создавать файлы `inventory.txt` без необходимости вручную писать код KeyValues.

## 🚀 Возможности
* Поддержка всех скинов, ножей, перчаток, агентов и кейсов.
* Настройка точного износа (Float) и качества (StatTrak™).
* Возможность задать кастомное имя (Name Tag).
* Автоматическое определение слотов и экипировка на стороны CT / T.
* Защита от вылетов игры (генерация правильного блока `default_equips`).

## 🛠 Как использовать
1. Откройте сайт.
2. Выберите нужные предметы.
3. Нажмите «Скачать inventory.txt».
4. Поместите файл в папку `csgo_gc` рядом с игрой.
5. Запустите `csgo.exe` и наслаждайтесь скинами!ы
